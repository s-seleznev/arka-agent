# Проверка поиска правил

Поиск возвращает кандидатов и не выбирает правило автоматически. Данные запроса остаются SQL-параметрами; доступ проверяется до поиска и повторно перед возвратом.

| Запрос | Получено кандидатов | Проверка |
|---|---:|---|
| 123123 | 1 | Точное числовое название: 9/225 |
| 71 | 2 | Исходный ID71 и название «71» у2/2692; требуется выбор |
| Количество мастита (с пробелом в конце) | 20 | 10/4929 первым; крайние пробелы названия нормализуются |
| cows for insemination | 20 | Английские термины переводятся только для поиска; 541 среди кандидатов |
| insemination | 20 | Несколько разных правил |
| genomic evaluation | 3 | Включён 22/4153 |
| 541 | 1 | Точный исходный ID |
| 20:541 | 1 | Точная пара компании и списка |
| Список на осеменение по синхронизации | 20 | 541 первым; точное название выше текстовых совпадений |
| осеменение | 20 | Несколько разных определений, требуется уточнение |
| какие коровы у меня на осеменение | 20 | 541 присутствует на позиции 9; это кандидат, не эталон выбора |
| на семя | 20 | 541 присутствует на позиции 9; расширение поиска, смысл запроса не подтверждён |
| геномная оценка | 3 | Включён 22/4153; одинаковое назначение не объединяет источники |
| сделай мне список не осемененных коров | 20 | Реальная формулировка сообщения 3382; историческая связь со списком не устанавливалась |
| Сделай список коров с пропущеным осеменением за прошлую неделю | 20 | Реальная формулировка сообщения 199; период и условия нужно читать из конкретного правила |

По умолчанию поиск выбирает последний импортированный снимок для исходной пары company/list; сохранённый ID v1 по-прежнему читается напрямую. Проверены default binding v2, явно запрошенная v1 и pinned binding ID v1.

Чужой пользователь получает пустой поиск и `null` при чтении; текст `' OR true --` не выполняется как SQL. Наличие нескольких кандидатов сохраняется независимо от готовности компиляции. В тесте девелоперская подстановка пользователя отключена.

Четыре unit-теста проверяют токены, сохранение отрицания/исходной фразы и безопасное формирование tsquery. Пятнадцать живых поисков завершились за 258–362 мс при параллельном запуске; это единичный прогон, не p95 и не нагрузочная приёмка.

Ограничения: русский морфологический поиск расширяет кандидатов, но не доказывает соответствие условиям. Отрицания сохраняются в исходной фразе и ранжировании, но не заменяют проверку дерева. Выражение «на семя» не найдено в проверенных исходных переписках; расширение до «на осеменение» используется только для поиска альтернатив.

Воспроизведение из `agent-app/`:

```bash
node --conditions=react-server --import tsx --test tests/unit/rule-search.test.ts
node --conditions=react-server --import tsx scripts/rules-search-audit.ts
```

Полные кандидаты, исходные формулировки и SHA реализации: [search-audit.json](search-audit.json).

Независимый полный прогон: 9504/9504 запросов PASS — 6735 точных составных ключей первым результатом и 2769 уникальных названий среди кандидатов. Все 15 ранее найденных ошибок устранены; [search-exhaustive-audit.json](search-exhaustive-audit.json), предыдущий неуспешный прогон сохранён отдельно.
