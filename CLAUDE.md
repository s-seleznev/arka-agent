# Head of Product Test Case — локальная подготовка тестового задания для АРКА

Рабочая копия тестового задания CPO в АРКА: исследовать запросы к ИИ-консультанту Аркаше, сформулировать работу со списками животных и показать её в существующем HTML-прототипе.

Подготовка проекта и локальная исходная событийная база фермы завершены. `agent-app/` построен на официальном Vercel AI Chatbot: работают история, документы, фотографии, база знаний, интерактивная таблица животных и управление этой таблицей агентом. Продуктовая и фермерская базы подключены раздельно. Локальный runtime и конфигурация моделей описаны в docs/project/ARCHITECTURE.md; готовность production не подтверждена.

## Environment

Рабочая папка: `<project-root>`.

Источник: `<private-source-directory>`. Оригиналы не изменять и не удалять. Копии 69 исходных файлов проверены по SHA-256.

`agent-app/` поддерживает прямую OpenAI-compatible модель через `AI_PROVIDER_BASE_URL`, `AI_PROVIDER_API_KEY` и `AI_MODEL_ID`; секреты не хранятся в репозитории. Чатовая база локально использует отдельную БД `arkasha_chat`, а исходная база фермы — `arka_test` в том же локальном кластере. Vercel project: `arkasha-agent`. Предыдущий deployment содержит старый минимальный интерфейс; новый продукт публикуется после подключения production Neon. `AUTH_SECRET` и private Blob уже заведены в Vercel. CSV содержат многострочные поля и удвоенные кавычки. Использовать CSV-парсер с `newline=''`, `encoding='utf-8-sig'`, `delimiter=','`, `quotechar='"'`, `doublequote=True`; не считать строки через разделение текста по переводу строки. Флаг is_integrator и служебный creator_id=2 описаны в data/README.md; содержательный анализ ещё не выполнен.

## Development

Локальный просмотр без установки зависимостей:

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory '<project-root>/prototype'
```

Открыть [оглавление](http://127.0.0.1:8765/) или [каталог компонентов](http://127.0.0.1:8765/shared/templates/index.html). Остановить сервер сочетанием Ctrl+C. Если порт занят, выбрать свободный и заменить его также в адресе браузера; чужой процесс не останавливать.

Полное пересоздание и проверка базы:

```bash
./scripts/db-check.sh
```

Команда создаёт изолированный кластер и `arka_test`, применяет десять миграций, загружает справочники, дважды строит одинаковый набор по `seed=42`, записывает две тестовые фермы и 80 животных, затем проверяет события, временные срезы, формулы, RLS, индекс и десять эталонных выборок.

Большой набор для стенда:

```bash
./scripts/db-generate-scale.sh 42 6 8500
```

Команда пересоздаёт базу, генерирует 6 ферм по 8 500 животных и обновляет индексированную проекцию `animal_state_query`.

Отдельные команды:

```bash
./scripts/db-start.sh
./scripts/db-reset.sh
./scripts/db-generate.sh 42
./scripts/db-stop.sh
./scripts/db-destroy.sh arka_test --yes
```

`db-reset.sh` и `db-destroy.sh` жёстко ограничены именем `arka_test`. Генератор помечает каждую запись как `GENERATED TEST DATA`; исходные CSV не импортируются.

Проверка синтаксиса двух внешних скриптов:

```bash
node --check '<project-root>/prototype/shared/sidebar.js'
node --check '<project-root>/prototype/shared/icons-loader.js'
```

Команд install/build для прототипа нет. Не добавлять инфраструктуру сборки только ради подготовки.

Чат-продукт Аркаши, команды выполнять из `agent-app/`:

```bash
corepack pnpm install
corepack pnpm run db:migrate
corepack pnpm dev
corepack pnpm run check
corepack pnpm exec tsc --noEmit
corepack pnpm exec playwright test tests/e2e/farm-agent.test.ts tests/e2e/farm-workspace.test.ts --project=e2e --reporter=line
corepack pnpm run farm:benchmark
corepack pnpm run build
```

`corepack pnpm dev` запускает приложение на `localhost:3000`. Чатовая база и Blob хранят продуктовые данные; исходная база фермы подключается только на сервере через `FARM_DATABASE_URL`.

## Code culture

Результат по заданию включает поставленный HTML-прототип, исходную событийную базу и отдельное приложение Аркаши. Следующие правила относятся ко всем дальнейшим изменениям продукта.

### Prohibited

- Скрытые обходные решения, пустые заглушки и обещания исправить позже вместо явного ограничения.
- Дублирование логики, когда достаточно существующего компонента; копирование экрана допустимо по prototype/shared/README.md.
- Связывание независимых частей без необходимости и молчаливое подавление ошибок.
- Значения в коде, которым место в конфигурации; заготовленные ответы допустимы и требуются заданием.
- Изменения исходных данных, новые зависимости и выход за согласованный объём без обоснования.

### Required

- Обосновывать решения; перед новым компонентом описывать его входы, выходы и состояния.
- При изменении архитектуры сначала обновлять ARCHITECTURE.md.
- В комментариях к неочевидным решениям объяснять причину.
- Показывать ошибки явно; недоделанное честно фиксировать в DEVLOG.md.

## Design system

Использовать уже поставленную библиотеку АРКА. Не заменять её на shadcn/ui, React, Tailwind или другую систему и не вводить новые темы в рамках подготовки.

| Слой | Фактическая реализация |
|---|---|
| Компоненты и поведение | HTML-шаблоны, components.css, существующие скрипты |
| Внешний вид | Семантические CSS-переменные в prototype/shared/tokens.css |
| Варианты и композиции | Модификаторы компонентов, layout.css, shared/templates/patterns/ |

Использовать готовые классы, типографику, отступы и иконки. Новые визуальные параметры связывать с существующими токенами; не переопределять смысл классов. Если нужного блока нет, действовать по правилам prototype/shared/README.md. Системный шрифт предусмотрен исходным комплектом; брендовый шрифт не устанавливать.

Для каждого интерактивного компонента реализовывать применимые состояния `default`, `hover`, `pressed`, `focus-visible`, `disabled`, `selected`, `open` и `active`. Компонент без реального действия, клавиатурного доступа или визуальной обратной связи считается незавершённым.

## Style conventions

Документация проекта — на русском, обычные Markdown-ссылки, даты в тексте — ДД.ММ.ГГГГ. Имена исходных файлов и относительные пути сохранять. В прототипе соблюдать форматы и классы из prototype/shared/README.md.
