# Выращивание и перемещение молодняка

## Отбор на перевод
Группа 24 и возраст>=70 дней → кандидаты на групповое содержание(5158).
Группа 23, возраст>=100 дней, полТёлка → кандидаты на доращивание(5159).
Группа 20, лактация 0, возраст>=13 календарных месяцев → кандидаты под осеменение(5160). Не переводить 13 месяцев в 390 дней; нужны календарный возраст/граница даты рождения.
Целевую группу не придумывать. Скилл показывает кандидатов, не записывает перемещение.

## Прочие команды
Обезроживание: Тёлка, возраст 65–150 дней, дата обезроживания пуста(5204).
Веса: использовать lastWeightKgдля последнего веса; диапазон включительный при формулировке «от…до…». Для прироста нужны два измерения и интервал, lastWeightKgне является привесом.
5151 в названии 0–90 дней, но условие<=120. Для свободного запроса пользователя 0–90 применяй его границы, а не исходную ошибку. Сохранённый список воспроизводится без исправления.
Состав молодняка 5195 ограничен лактацией 0 и группами 20/24/17/23; это локальная область, не универсальное определение всех молодых животных.

## Результат
Номер, возраст, пол, текущая группа, последний вес/дата при необходимости. При отсутствии соответствия номеров групп кодам стенда не подставляй случайную группу. Профилактика новорождённых — vaccination, болезни — health.

## Короткие отчёты профиля
«Бычки на продажу» — список подготовки, включая ожидающих: sex=MALE, isExited=false, ageDays<=60. Не выдумывай статус SALE_READY. saleReadiness показывает «Готов» при возрасте>=14 дней и последнем весе>=50 кг, иначе «Ожидание»; это допущение демопрофиля, не рекомендация по перевозке. Колонки: primaryIdentifier,birthDate,ageDays,lastWeightKg,dailyGainG,saleReadiness. Сортировка ageDays DESC. Если явно просят только готовых, добавь saleReadiness=Готов.
«Тёлки старше 12 месяцев» — isExited=false, sex=FEMALE, lactationNumber=0, ageMonths>=12 (профиль отчёта 12+). Колонки: primaryIdentifier,ageMonths,lastWeightKg,groupCode,statusCode. Группировка ageBand, сортировка ageMonths ASC. ageMonths — полные календарные месяцы; не заменяй их ageDays/30.
