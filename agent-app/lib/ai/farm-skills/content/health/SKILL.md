# Здоровье и обследования

## Гинекология и метрит
Секция 11: группа 11, лактация>0, дата проверки не в дату расчёта (5198). Секция 6: то же для группы 6 плюс пустая дата нормы метрита (5199). Для профиля пустая дата проверки тоже означает непроверенное животное: явно используй OR(is_empty,neq), а не молча полагайся на SQLNULL.
5203 для лечения метрита имеет широкую OR-ветвь всей группы 11. Не превращать эту выборку в диагноз и не назначать лечение. Запрос на лечение означает список принятого контроля, не медицинское решение.

## Обследования
Кетотест 1: лактация>0,7–10 дней доения, дата первого теста пуста. Кетотест 2: лактация>0,14–17 дней доения, минимум 7 дней с первого, второй пуст (5200). Для двух этапов профиль использует OR с устранением дублей. Для результатов 5183 нужны обе даты, не одна.
pHмочи: группа 9, дней до ожидаемого отёла<=14 (5202); верхнее условие без нижней границы сохранено. Результаты 5181 — дата исследования заполнена.
Мастит>=8 случаев текущей лактации (5125), не строго>8. Группа 13(5124) — санитарная секция, а не доказанный диагноз. Соматика>=750 на двух последних КД(5164), единицу сверить по полю.
Копыта: для стенда очередь 5207 —120–127 дней доения и отсутствие события расчистки; пока DATE_OF_EVENT_0 не сопоставлено с конкретным событием, не выполняй упрощённый отбор по возрасту лактации.5205(120–126 без проверки события) — другой вариант.

## Результат
Номер, группа, релевантные даты/результаты. activeDiagnosisCountподходит только для запроса «есть активные диагнозы», не заменяет конкретный мастит/метрит/кетоз. Никаких доз, назначений и записей лечения.

## Контроль болезней молодняка и диагностического отбора
Для недельного контроля диареи/пневмонии: лактация=0 и дата соответствующего события не ранее даты расчёта−7 дней (5265/5307). Это зарегистрированные случаи, не автоматическая диагностика.
Бруцеллёз (5079): контрольное представление живых животных с датой и примечанием отбора; нет условия назначения забора или положительного результата. Не считать его вакцинацией или очередью на забор.

## Короткие отчёты
«Новотельные для контроля» — isExited=false, lactationNumber>0, daysInMilk между 0 и 14 включительно. Колонки primaryIdentifier,daysInMilk,lactationNumber,yesterdayMilkKg,lastClinicalEvent,animalNote. Сортировка daysInMilk ASC. Не подменяй надой вчера последней дойкой. Группировка не нужна, если все в одном отделении.
«Животные в работе» — все активные назначения различных протоколов: isExited=false, activeProtocols is_not_empty. Колонки primaryIdentifier,groupCode,activeProtocols,protocolProgress,nextProtocolDate,protocolResponsible; сортировка nextProtocolDate ASC. Отчёт показывает существующие назначения, не назначает препараты. Завершённые и отменённые назначения исключены, несколько активных назначений показаны в одной строке животного с сохранением названий и прогресса.
