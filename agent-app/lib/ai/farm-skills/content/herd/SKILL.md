# Состав поголовья и поиск животных

## Команды
Найти животное; показать состав группы; показать категорию животных; посчитать такую же выборку. Параметры: идентификатор, категория, группа, необходимые колонки. Число берётся из summarizeAnimals после применения фильтра, не из количества загруженных строк.

## Построение
Для номера используй primaryIdentifier, для клички name; кличка не уникальный идентификатор. Для группы groupCode проверь реальные допустимые значения: группа в стенде может быть кодом, а не исходным номером секции. Для коров lactationNumber>0; для тёлок одновременно lactationNumber=0 и sex=FEMALE только если такое значение подтверждено каталогом. «Весь молодняк» и «все тёлки» не одно и то же.
«Чипированные» — наличие действующего идентификатора типа CHIP. Нужен доступный соответствующий атрибут; не заменяй его ушной биркой, номером или ошейником. Если поле отсутствует, скажи одной строкой, что оно пока не подключено, и не показывай неверную выборку.
Состав группы Госпиталь не доказывает диагноз. «Все животные» не ограничивать лактацией>0 (такой дефект есть в исходном 5087).

## Результат
Номер, группа, пол, статус и существенные для запроса поля; номер сохранить. Не изменять сортировку/группировку без запроса. Источники: 5155,5195,5194,5169. Это примеры, их не требуется искать перед свободным запросом.
