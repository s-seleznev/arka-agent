# Арка — приложение прототипа

Next.js-приложение на Vercel AI SDK: чат, история, документы и таблица животных. Агент и пользователь работают с одним сохранённым представлением таблицы.

[Публичный прототип](https://arka-agent-demo-2026.vercel.app) · [Публикация, проверки и ограничения](../docs/project/DEPLOYMENT.md)

## Запуск

Команды выполняются из `agent-app/`. Нужны доступные базы и заполненный `.env.local` по `.env.example`.

```bash
corepack pnpm install
corepack pnpm run db:migrate
corepack pnpm dev
```

Приложение доступно на [localhost:3000](http://localhost:3000). Миграция изменяет продуктовую БД; перед применением к существующим данным нужна резервная копия. Порядок работы с базой фермы описан в [DATABASE.md](../docs/project/DATABASE.md). `scripts/db-check.sh` не является безопасной проверкой существующего большого набора: он пересоздаёт тестовую базу.

## Runtime и данные

- При `AI_RUNTIME=codex-app-server` запросы выполняет Codex app-server с настроенной локальной авторизацией; модель задаётся `CODEX_MODEL`.
- При `AI_RUNTIME=openrouter` используется только `openrouter/free` или модель с суффиксом `:free`, без платного fallback. Название чата формируется без модели.
- В остальных API-режимах прямой OpenAI-compatible провайдер использует `AI_PROVIDER_BASE_URL`, `AI_PROVIDER_API_KEY`, `AI_MODEL_ID`. Резервная ветка использует Vercel AI Gateway и требует его настройки.
- `POSTGRES_URL` подключает продуктовую БД, `FARM_DATABASE_URL` — базу фермы. Локально это отдельные БД; в публичном демо они размещены в одной Neon БД. `FARM_ACTIVE_ID` ограничивает активную ферму поверх прав доступа.
- Секреты хранятся в `.env.local`, не в документации и Git. Файлы используют приватное хранилище и авторизованные маршруты.

Таблица уже подключена к базе: доступны колонки, дерево фильтров, сортировка, один уровень группировки, CSV и печать. Инструкции агента находятся в [каталоге скиллов](lib/ai/farm-skills/README.md).

## Проверки

Команды проверок не означают, что текущая версия их прошла:

```bash
corepack pnpm run check
corepack pnpm exec tsc --noEmit
```

06.09.2026 TypeScript и production-сборка прошли. Реальный OpenRouter с облачной БД вернул 20 животных за 43,933 с; с независимой проверкой таблицы — 49,558 с. Автоматический POST к публичному чату блокирует BotID; полная браузерная приёмка после исправления не выполнена. История проверок и их ограничения — в [журнале](../DEVLOG.md).
