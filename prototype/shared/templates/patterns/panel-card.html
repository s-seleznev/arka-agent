Panel Card · композиция + паттерн header / content / footer

В product-src нет отдельного PanelCard-компонента. Панели собираются из классов panel.module.scss + свободный DOM внутри. Базовый класс .panel — только bg и radius; padding, header и footer добавляются поверх. Для collapsible-варианта используй Accordion (см. components/accordion.html) — он уже использует panel-классы внутри.

Panel classes (panel.module.scss — composable CSS-modules):
  .panel               bg surface-1, radius 8                    — base
  .smallPanel          → panel + radius 6                        — компактная
  .largePanel          → panel + radius 12                       — главная карточка (default)
  .darkPanel           → panel + bg surface-3                    — на белом bg, выделяется серым
  .largeDarkPanel      → darkPanel + largePanel                  — крупная тёмная
  .borderedPanel       → panel + 1px border border-muted         — на плоском bg
  .smallBorderedPanel  → borderedPanel + smallPanel              — компактная с границей

Card pattern (собирается вручную):
  <div.panel.large-panel>
    <div.card-header>         header с title и actions
      <div.card-header-left>   h2.card-title + subtitle (опц.)
      <div.card-header-right>  кнопки (FunctionButton / Button)
    <div.panel-content>       основной контент — padding 24
      {children}
    <div.card-footer>         опциональный футер (НЕ «Отмена/Сохранить» — это
                               модальный паттерн, см. components/modals.html):
                               «Показать ещё», статус-инфо, ссылки на детали

Padding конвенция

В коде product-src: panelStyles.largePanel + `p-content-grid` (=24px всего внутри).
В этом шаблоне — явный padding 24 через .panel-content.
Card-header padding-bottom 16 = gap между header и content.
Card-footer padding-top 16 = gap между content и footer.
