Table Toolbar · структура thead + action bar

В product-src «toolbar таблицы» — это thead > tr.headerRow. Он состоит из колонок с заголовками, sticky-ячейки с TableSettingsPopoverButton справа и опционального .actionBarCell, который появляется при выделенных строках (selectedItems.length > 0) и абсолютно позиционируется поверх всех ячеек через position: absolute; inset: 0;. Bulk-actions рендерятся через проп tableProps.renderActionBar(selectedItems).

Popover buttons · anatomy

Два поповер-триггера, используемых в toolbar'е таблицы. Оба — FunctionButton medium20. TableSettingsPopoverButton — shared (одна кнопка на всю таблицу), открывает drawer с сортируемыми чипами столбцов. TableColumnSettingsPopoverButton — per-column, с opacity 0 по умолчанию (.headerIconWithOpacity), появляется на hover ячейки. Иконка меняется в зависимости от состояния сортировки: filter → sortAsc / sortDesc.
