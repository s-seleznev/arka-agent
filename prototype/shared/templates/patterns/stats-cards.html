Stats / Metric cards · ReproductionMetricCard

Карточка KPI с целевым значением и дельтой. Используется на analytics-dashboard'ах репродукции: «CR», «Риск-группа», «Стельность» и пр. Высота фиксированная — 156px. Сетка 2×1 внутри: слева — факт + дельта, справа — цель. Цвет значения «Факт» меняется по отношению к target/deviationThreshold. Цвет дельты и иконка — по знаку delta.

Color rules (getMetricColorForegroundClassName)

value < deviationThresholdPercent  →  text-error    (критическое отклонение)
value < targetPercent              →  text-warning  (ниже цели, в допуске)
value >= targetPercent             →  text-success  (цель достигнута)
иначе (nil target/threshold)       →  text-soft     (нейтральный)

delta > 0  →  text-success + icon metric-positive
delta < 0  →  text-error   + icon metric-negative
delta = 0  →  text-soft    + icon metric-unchanged

Matrix — все состояния по delta + metric color

Четыре типовых состояния: delta positive + value выше цели (зелёный+зелёный), delta negative + value в допуске (красный+жёлтый), delta neutral + value ниже порога (серый+красный), missing target (всё text-soft + unchanged).
