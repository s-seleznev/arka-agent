ReportCardBuilder · 3 состояния + settings form

Паттерн для «собери-свой-отчёт» карточек. Composition: ReportCardBuilderCard (outer) + ReportCardBuilderFormSection (collapsible-секции внутри settings-form) + ReportCardBuilderFormArrayItem (элемент массива — filter-config, grouping-config). Использует Panel + Accordion + Button + Form. 3 состояния — view / update / create — отличаются набором кнопок в header и наличием settings-form. Visual transition: view — обычная панель bg-surface-1, editing (update/create) — accent-tinted bg accent-opaque-container-soft + border accent-muted, duration fast-01.

Дефолтное состояние. Update state — editing mode с settings form

При нажатии «Настройки» карточка переходит в update: title меняется на updatingTitle («Настройки графика и таблицы»), справа — кнопки «Отмена» + «Сохранить». Border становится accent-muted, bg — accent-opaque-container-soft. Settings-form раскрывается через Accordion. Внутри — ReportCardBuilderFormSection'ы: Период / Группировки / Фильтры / Ось Y. Content (отчёт) виден под ними — можно сравнивать по ходу редактирования.

Create state — новый отчёт, «Создать» вместо «Сохранить»

Аналогично update, но название creatingTitle, основная кнопка — «Создать» (не «Сохранить»). shouldRenderCancelButtonForCreate (default true) — показывает «Отмена» (для create тоже). Если false — только «Создать». Отчёт внизу пустой / placeholder до первого calculate.
