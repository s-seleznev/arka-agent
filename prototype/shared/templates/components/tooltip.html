Tooltip · структура и placement'ы

Tooltip рендерится через @floating-ui/react FloatingPortal — в document.body, с автоматическим flip/shift. Триггер — children (любой элемент, оборачивается через cloneElement с useHover). Если children не передан — рендерится дефолтная иконка help-circle-filled (neutral-muted, cursor help). Внутри — title (опц.) + content, typography descriptionLarge[Strong] 12/400-500/16. В demo используется static-позиционирование, чтобы показать все 12 placement'ов одновременно.

Source: Tooltip/index.tsx + TooltipPortal/index.module.scss + TooltipBody/index.tsx + hooks/useTooltip.ts

Props (важные)

title?            заголовок (descriptionLargeStrong)
content           тело подсказки (descriptionLarge)
placement         один из 12 (default 'top')
offset            доп. смещение от reference (default 8px уже добавлен в useTooltip)
isLarge           padding 12/16 вместо 8/12
maxWidth          override max-width: 264px
delay             задержка показа (ms), default — мгновенно
mouseOnly         только hover, без keyboard focus
isDisabled        отключает tooltip полностью
withPointerCursor default true, добавляет cursor: pointer на reference

Placements — 12 позиций

4 стороны × 3 выравнивания (center/start/end). В реальном коде @floating-ui применяет flip() — если нет места в желаемом placement, переключается на противоположный. shift() смещает вдоль основной оси чтобы не выходить за viewport. В demo позиции статичны.

Sizes · default vs isLarge

isLarge=true увеличивает padding с 8 12 до 12 16. Остальное — без изменений. Используется для более «внятных» тултипов с title + длинным описанием.

Source: TooltipPortal/index.module.scss:7-17 (.root + .large padding override)

Content — title + content / только content

TooltipBody рендерит title (если передан, descriptionLargeStrong) + content (descriptionLarge). Gap между ними — 4px. maxWidth override позволяет сделать более узкий/широкий tooltip если контент требует.

Max-width 264px · hugs vs wraps

В коде задан только max-width: 264px (без width и min-width). Поведение: короткий контент → тултип обнимает по ширине контента (content-width). Длинный → переносится, фиксируется на 264px.

Source: TooltipPortal/index.module.scss:3-7 — --tooltip-max-width: 264px, max-width: var(--tooltip-max-width). Нет min-width / width.

Trigger — default help-icon vs custom reference

Если в <Tooltip> не передан children — рендерится дефолтная иконка help-circle-filled размером 16 (SizeVariants.size16), цвет neutral-muted, cursor help, на hover neutral-hover. Если передан children — он оборачивается через cloneElement с useHover и получает cursor: pointer (если withPointerCursor=true, default).
