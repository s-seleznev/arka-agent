Skeleton · 4 компонента + context API

В коде Skeleton — это wrapper с context'ом (useSkeletonContext): определяет isLoading, его помощники переключают skeleton ↔ content. Под капотом используются 4 sub-компонента: Skeleton.Block (базовый примитив), Skeleton.Text (типографика-aware), Skeleton.LineChart, Skeleton.BarChart. Все используют одну и ту же pulse-анимацию: bg neutral-container-default ↔ neutral-container-soft, длительность 2s, easing cubic-bezier(0.4, 0, 0.6, 1).

Source: Skeleton/index.tsx + components/SkeletonBlock/ + SkeletonText/ + SkeletonLineChart/ + SkeletonBarChart/

Skeleton (wrapper, context provider)
  .isLoading → switches children через renderWithSkeleton(skel, content)

Skeleton.Block — основной примитив:
  props: { size } или { width, height, borderRadius } + isRound
  DOM: div[role=status, aria-busy, aria-live=polite]
         div.inner (radius 4, pulse animation, bg neutral-container-default)

Skeleton.Text — обёртка Block с typographyVariant + size (small/medium/large):
  heights: heading2 20, bodyMediumStrong 20, bodyLargeStrong 24,
           bodySmall 12, bodySmallStrong 16, descriptionLarge 8, descriptionLargeStrong 8
  widths per size: см. SKELETON_TEXT_WIDTHS dict в SkeletonText/index.tsx

Skeleton.LineChart — SVG path, padding 75/122/74, currentColor pulsing
Skeleton.BarChart — 12 bars по 20% width, heights responsive (base 148px)

Context helpers:
  renderWithSkeleton(skel, content, isStatic?) — переключает по isLoading
  renderStaticContent(content)                  — reset context
  renderWithoutSkeleton(content)                — content только при !isLoading
  getSkeletonClassNames(skel, content)          — conditional className

Animation tokens

--duration-pulse: 2s
--easing-pulse: cubic-bezier(0.4, 0, 0.6, 1)
@keyframes pulse { 50% { bg: neutral-container-soft } }
Base bg: neutral-container-default, radius 4 (full когда isRound=true)

Skeleton.Block — базовый примитив (rectangle / square)

Два режима props: { size } (квадрат) или { height, width?, borderRadius? }. width default = '100%' если не передан. Custom borderRadius переопределяет дефолтные 4px.

Skeleton.Text — heights + widths из TypographyVariants dict

Для каждого TypographyVariants определены высота и 3 варианта ширины (TextSkeletonSizes.small | medium | large). Высота имитирует «наполненность» x-height буквы в данном размере шрифта, ширина — типичная длина текста. Встроено в любой Typography через skeletonSize prop.

Композиции — реальные use-cases

Обычно skeleton собирается из нескольких Skeleton.Block / Skeleton.Text для имитации структуры контента. Два типичных паттерна: (1) карточка — avatar-круг + title + описание + action; (2) строка таблицы / списка — несколько text-блоков в флексе.
