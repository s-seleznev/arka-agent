TextLink · структура и 3 режима рендера

Минималистичный компонент. SCSS модуль содержит ТОЛЬКО text-decoration: underline. Цвет — fg-default, наследуется от глобального правила a { color } в styles/global.scss:46. Hover / focus / active / visited не задаются — только underline + inherit color. Логика рендера: 3 варианта в зависимости от props.

Source: TextLink/index.tsx + index.module.scss (только 2 правила: .root + print override) + styles/global.scss:46 (global a rule)

Props → render:
  isDisabled=true           → <Typography variant>           БЕЗ underline (не link)
  'href' in other           → <a href target rel>             internal HTML anchor (external / mailto / tel)
  иначе                     → <Link to from>                  tanstack Router Link

className (для link-режимов):
  styles.root                   — text-decoration: underline
  typographyStyles[variant]     — font-size/weight/line-height

Default typographyVariant: bodySmall (14/400/20).
typographyVariant=inheritText — для использования внутри Typography-контекста
(наследует родительский font, нужно для inline-link'ов в Markdown, table cells).

Особенности

• НЕТ hover-эффекта (color не меняется, underline и так стоит)
• НЕТ visited-стиля
• НЕТ accent / «синий» цвет — всегда fg-default (тёмный текст) + underline
• При print underline снимается (@media print)
• disabled рендерит обычный Typography-текст без underline (не серый, не muted)

typographyVariant — размер link'а

Default — bodySmall (14/400/20). Вариант передаётся через prop typographyVariant и применяется через className typographyStyles[variant]. Для inline-использования внутри другого Typography — inheritText (без font-правил, наследование от родителя).

Использование · inline vs standalone

Внутри параграфа — цвет наследуется от родительского текста, ссылка визуально сливается и отличается только подчёркиванием. Отдельной строкой (standalone) — всё то же самое, просто block-level. В Markdown и таблицах часто typographyVariant=inheritText — размер берётся от родителя.

External links · target=_blank, mailto, tel

Если в props передан href — рендерится нативный <a>, куда можно прокинуть target="_blank" и rel="noopener noreferrer". Для mailto: и tel: — то же самое через href. Визуально — те же стили (underline + fg-default), разница только в семантике.

isDisabled — рендер как Typography без underline

isDisabled=true меняет разметку: вместо <a> / <Link> рендерится <Typography variant> — обычный span БЕЗ underline. Цвет НЕ меняется на muted/disabled — остаётся fg-default. Если нужен «визуально выключенный» вид — обернуть снаружи в className="text-muted" или передать через TypographyVariants с muted-цветом.
