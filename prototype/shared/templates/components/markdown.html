Markdown · структура и маппинг HTML → Typography

Под капотом — ReactMarkdown с плагинами remarkGfm (tables, strikethrough, checkbox), remarkBreaks (\n → <br>), rehypeRaw + rehypeSanitize (safe raw HTML). Root — <Typography tag="div" variant={bodyMedium}>. Каждый HTML-элемент маппится в свой Typography с нужным variant и/или кастомный wrapper. Типичное use-case: AI-ответы (Аркаша), описания, help-тексты, rendered markdown-поля.

Source: Markdown/index.tsx + constants.tsx (MARKDOWN_COMPONENTS mapping) + index.module.scss (spacing + wrappers)

Spacing правила:
  > * + *  margin-top 16      (между direct children)
  ul, ol   margin-block-start 16, padding-inline-start 20
  li + li  margin-top 16
  hr       margin 16 0
  table + * margin-top 32     (extra разделение после таблицы)

Headings · h1-h5

Все headings — Typography с соответствующим heading-variant. Между соседними элементами — margin-top 16px из общего правила .root > * + *.

Source: constants.tsx:24-38 (h1-h5 mapping)

h1 — 28 / 700 / 32

h2 — 22 / 700 / 24

h3 — 18 / 700 / 20

h4 — 16 / 700 / 20

h5 — 14 / 700 / 20

Inline · bold / code / links

b и strong оба → bodyMediumStrong (16/500/24). Inline code — bodySmall шрифт + padding 1/4 + bg neutral-opaque-container-muted + radius 4. Ссылки идут через TextLink компонент (см. text-link.html), для внутренних ссылок используется to prop tanstack-router, для внешних — href + target=_blank.

Source: constants.tsx:14-56 (b/strong/a)

Обычный текст параграфа содержит жирный b, жирный strong, inline code с моноширинным шрифтом и подсветкой, а также ссылки: внутренняя ссылка и внешняя ссылка.

Например, если корова имеет CR = 45%, а целевое значение ≥ 42% — показатель в норме.

Lists · ul (disc) / ol (decimal) / nested

Списки с стандартным list-style (disc для ul, decimal для ol). Padding-inline-start 20px, gap между items — 16px. Вложенные списки тоже получают margin-block-start 16.

Source: constants.tsx:57-79 (ul/ol/li) + index.module.scss:10-18 (spacing)

Параметры проверки коровы

  • Инвентарный номер и кличка
  • Группа, статус воспроизводства
    • Телка / первотёлка / дойная
    • Стельная / яловая / в охоте

Blockquote · Pre (code block)

Blockquote обёрнут в .blockquoteWrapper: padding 16/24, radius 8, bg neutral-opaque-container-muted. Внутри — blockquote с padding-left 12 + border-left 2px border-muted, typography bodySmall. Pre — отдельный блок для многострочного кода: overflow: auto, padding 12, radius 12, bg neutral-opaque-container-muted.

Source: constants.tsx:105-117 (pre/code/blockquote) + index.module.scss:25-42 (.blockquoteWrapper + .pre)

Если CR по стаду ниже 40% — первый шаг диагностики: проверить технику осеменения у каждого специалиста. В 70% случаев проблема именно там.

    lactations(period: $period) {
      number

      dailyMilkAvg
      daysInMilk
    }
  }
}

Table · через remarkGfm

Markdown-таблицы (через GitHub-Flavored Markdown plugin). Обёрнута в .tableWrapper (overflow auto для узких viewport'ов). Table: border 1px + radius 8 + border-collapse: separate (чтобы radius работал). Thead — с отдельным border-top-left/right-radius на первой/последней th первой строки. Th — descriptionLargeStrong (12/500/16) на neutral-opaque-container-muted фоне. Td — bodySmall (14/400/20) с white-space: pre-wrap.
