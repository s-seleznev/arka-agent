Avatar · структура и особенности

Минималистичный компонент: 24×24, radius 6, grid place-items-center, показывает name[0] — первую букву. Background = color-{color}-container-default (прозрачный alpha 0.1). Color = fg-soft. Доступные цвета — 8 (success, warning, error, info, status01-04); neutral и accent исключены из итератора. isLoading=true всегда даёт neutral фон + Loader.

Source: Avatar/index.tsx + index.module.scss + component-tokens.json (avatar.size = 24px)

Avatar DOM (index.tsx:69-86):
  span.root[role=img][aria-label={name}]          ← display: grid, 24×24, radius 6
                                                    style: bg = {color}-container-default
    Typography bodyMedium (16/400/24)             ← name[0] — первая буква имени
                                                    или '?' если name пустое
                                                    или Loader если isLoading=true

Props:
  name?          первая буква используется как content. Default ''
  color?         ColorVariants (default neutral, но через AVATAR_COLOR_ITERATOR
                 выдаются только status/success/warning/error/info)
  isLoading?     показывает Loader вместо буквы, bg переключается на neutral

Использование в проде

CompanySelector (в sidebar)    — Avatar с буквой компании + иконка company
User-меню (sidebar-bottom)      — Avatar с буквой оператора
Список фермы / групп            — стабильный цвет через AVATAR_COLOR_ITERATOR
                                  (хешируется id → всегда один и тот же цвет
                                   для одной сущности)

Colors — 8 вариантов (без neutral и accent)

В AVATAR_COLOR_VARIANTS (index.tsx:21-23) фильтруются neutral и accent. Остаются 4 семантических (success/warning/error/info) + 4 status (01-04). Все на фоне container-default (alpha 0.1) того же цвета. Текст — fg-soft (неокрашенный, нейтрально-тёмный).

States — name / no name / isLoading

Три состояния из index.tsx:60,85: (1) есть name → первая буква; (2) name пустое → '?'; (3) isLoading=true → Loader, bg принудительно neutral (неважно какой color передан).

Source: Avatar/index.tsx:60 (missingNamePlaceholder) + 76-82 (bg switch для isLoading)

name="Иван" — первая буква 'И' И
name="" — fallback '?' ?
isLoading=true — Loader + neutral bg

AVATAR_COLOR_ITERATOR — стабильный color по input value

makeColorByValueIterator(AVATAR_COLOR_VARIANTS) создаёт детерминированный маппер: хеширует input (string | number) → один и тот же цвет всегда. Это гарантирует что avatar одного и того же оператора/компании/группы стабильно выглядит одинаково между рендерами и экранами. В demo — имитация для 8 имён, цвет вычисляется как hash(name) % 8.
