Buttons · структура трёх компонентов

В product-src три разных button-компонента: Button (основной CTA — с фоном), FunctionButton (текст/иконка без фона, меняет только цвет на hover), CloseButton (icon-only с bg-hover). Разные sizes enum'ы и разные hover-модели. Не путать между собой: отличаются файлами в src/shared/components/, пропсами, и визуальным поведением.

Button · 3 variants × 3 themes (medium36 default)

9 комбинаций: variant (primary/secondary/ghost) × theme (accent/neutral/destructive). Primary — solid bg, Secondary — container bg (полупрозрачный), Ghost — transparent default, bg появляется на hover. Default theme: primary→accent, else→neutral. Destructive не является default ни для чего — задаётся явно.

Button · states

Hover можно проверить мышкой на любой кнопке в шаблоне. Здесь явно показаны pressed, disabled, loading. В коде состояния управляются через isPressed prop (forced press), isDisabled, isLoading → классы .pressed / .disabled / .loading. При loading: icon и text получают opacity: 0, поверх накладывается Loader (абс-позиц, inset 0).

Button · icon-only (withOnlyIcon)

Если iconVariant задан, а children нет (или скрыты через shouldHideLabelOnMobile) — рендерится без текста, с изменёнными padding и radius. Radius более «квадратный» (10 для medium36 вместо 8), чтобы кнопка выглядела как кнопка-иконка, а не растянутая.

FunctionButton · variants × sizes (light theme)

4 variants × 3 sizes. Default: tertiary (color fg-soft) + large24. bg ВСЕГДА transparent — отличается от Button. Hover меняет color (--button-active-color): все non-failure → accent-hover, failure → error-hover. Failure используется для destructive-действий, которые по стилю должны выглядеть как ссылка.

FunctionButton · dark theme (isDark=true)

Применяется на тёмных поверхностях — тостах, модалках с dark header, PageHeader-слайдере. Colors берутся из dark-scale: primary → accent-200, secondary → neutral-50, tertiary → neutral-200. Hover-цвет — accent-100 (не accent-hover). В Toast FunctionButton рендерится с isDark=true, variant=secondary (Source: Toast/index.tsx:50-56).

CloseButton · sizes × themes

Icon-only кнопка с иконкой x-close. 4 размера, 2 темы. Hover меняет только bg (в отличие от FunctionButton, который меняет color). onLight → hover bg neutral-container-hover; onDark → neutral-700. Радиус меняется по размеру (6 для large24, 4 для остальных).
