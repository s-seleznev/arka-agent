Структура · wrappers и отступы

Toast — одноуровневый div.root в виде flex-row с items-start. Дочерние элементы в порядке: Icon (скрыт для neutral) → div с текстом (через mr-a распихивает остальные к правому краю) → опциональные FunctionButton'ы → опциональная CloseButton. Все внутренние margin'ы заданы utility-классами (ml-8, ml-16, py-2). Toast — «dark» тема нотификации: фон --notification-dark-container-color (= --color-{variant}-soft), цвет текста --neutral-on-color (белый).

Пять вариантов из NotificationVariants. Default = warning. Для каждого — свой фон (--color-{variant}-soft, solid цвет). Иконка — белая (наследует от color: var(--neutral-on-color) на root). Для neutral иконка не рендерится (Toast/index.tsx:37).

withCloseButton — кнопка закрытия

Если withCloseButton=true, в конце рендерится CloseButton с theme=onDark и ml-16. По умолчанию false, поскольку тосты закрываются автоматически по таймеру (TOAST_TIMEOUT_MS). onDark тема = transparent bg, color --neutral-50, hover bg --neutral-700.

functionButtonProps — action-кнопки

Один или несколько FunctionButton рендерятся перед close'ом. Каждый с ml-16, isDark=true, variant=secondary (color --neutral-50). functionButtonProps — либо один объект, либо массив. При нажатии вызывается сначала onClose, затем собственный onPress (Toast/index.tsx:57-60).
