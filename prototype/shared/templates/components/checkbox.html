Checkbox · canonical DOM

Единственный правильный DOM для чекбокса. Копируй отсюда. Размер size-16/20/24 вешается на root .checkbox, не на .border. SVG лежит внутри .icon wrapper'а — именно .icon имеет scale: 0/1 transition, управляемый через aria-checked. Без этого иконка всегда видна и в натуральную величину.

Source: Checkbox/index.tsx:230-247 (DOM) + Checkbox/index.module.scss:82-110 (.border, .icon, scale по aria-checked)

<label class="checkbox normal size-20" aria-checked="true" aria-disabled="false"> <div class="border"> <span class="icon"> <svg><use href="../../icons.svg#check"/></svg> </span> </div> <!-- опционально, если withLabel --> <span class="label">Текст</span> </label>

Для indeterminate — aria-checked="mixed" + иконка #minus. Для disabled — aria-disabled="true". Для withLabel — добавить класс .withLabel на root (grid-template-columns меняется на auto 1fr). Combo-only правило: все модификаторы (.size-16, .withLabel, .colored, .normal, .icons) — только в combo с .checkbox.

Sizes × checked state

Три размера (size-16 / size-20 / size-24) × три state'а checked (unchecked / checked / indeterminate). Иконки внутри border: #check для checked, #minus для indeterminate. В unchecked состоянии иконка в DOM есть, но scale: 0 делает её невидимой.

Состояния

Hover/pressed/focus-visible меняют --checkbox-color и --checkbox-color-background. Disabled переключает aria-disabled="true" — убирает border, меняет фон на neutral-container-soft, иконка fg-disabled. Hover доступен реальный (навести мышью), остальные — симуляция через data-is-pressed / data-is-focus-visible.

withLabel — чекбокс с текстом

Когда передан label — product-src добавляет класс .withLabel (grid-template-columns переключается на auto 1fr). Текст оборачивается в Typography, variant зависит от size: size16 → descriptionLarge (12/400/16), size20 → bodySmall (14/400/20), size24 → bodyMedium (16/400/24). Label-элемент оборачивает всё (сам label кликабельный).

Source: Checkbox/index.tsx:91-96 LABEL_TYPOGRAPHY_VARIANT_BY_SIZE + index.module.scss:21-23 (.withLabel grid)

colored — кастомный цвет через CSS-переменную

Когда передан prop color — добавляется класс .colored + inline-style с переменными --checkbox-color-default/-hover/-pressed. Border в unchecked использует этот цвет (вместо border-soft). В checked — bg тоже этим цветом. Используется в фильтрах и легенде графиков.

Source: Checkbox/index.tsx:209-212 + index.module.scss:50-52 (.colored)

variant="icons" — не чекбокс, а toggle "видимость"

Альтернативный variant из enum CheckboxVariants.icons. В Checkbox.tsx:113-119 при variant=icons иконки по умолчанию: selectedIconVariant=IconVariants.eyeShow, unselectedIconVariant=IconVariants.eyeKeepOut. В SCSS правило одно: .icons .icon { color: fg-soft } — ни .border, ни scale, ни bg не переопределяются. Иконка всегда видна (scale default = 1), border — transparent wrapper без визуала. Состояние определяется тем какая именно иконка рендерится, а не стилизацией box'а.

Source: Checkbox/index.tsx:113-119 (selectedIconVariant/unselectedIconVariant defaults) + index.module.scss:119-123 (only `.icon { color: fg-soft }` rule)
