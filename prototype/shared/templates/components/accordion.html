rightTitleContent — доп. контент справа от title

Когда rightTitleContent передан — chevron получает класс mr-a (margin-right: auto), который распихивает chevron и rightTitleContent по краям. Title в этом случае без flex-1 (Accordion.tsx:185). Контент справа обычно это FunctionButton'ы или Badge. В реальном коде (cows/+$cowId/+info.tsx:248-250): flex-wrap, items-center, justify-content flex-end, gap 16. rightTitleContent может быть функцией (isOpen) => ReactNode — показываться только при открытом accordion.

Source: Accordion.tsx:153,185,192 (mr-a + title без flex-1 + normalizeToValue) + cows/+$cowId/+info.tsx:234-274 (реальный пример)

isChevronOnLeft — chevron слева от title

По умолчанию isChevronOnLeft = false — chevron справа. Если true — chevron рендерится перед title. Margin-right вместо margin-left. Используется в реальном коде для «График лактаций» на странице коровы.

Source: Accordion.tsx:117,181 (isChevronOnLeft conditional render)
