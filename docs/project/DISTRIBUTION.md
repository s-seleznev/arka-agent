# Состав распространяемого проекта

В Git остаются приложение, интерфейс, событийная схема БД, миграции, генераторы синтетических животных, восемь скиллов агента и документация разработки.

Исходные CSV и текст задания удалены. Полная версия сохранена отдельно в приватном архиве. Аналитический код, результаты, цитаты и готовый сайт находятся локально в `analysis/`, но вся папка исключена из Git. Производные выгрузки исходных правил в `rules/` тоже не публикуются. Локальные базы, секреты и настройки Vercel не изменены.

Опубликованная аналитика защищена серверным паролем: без сессии недоступны и страница, и JSON/CSV. Пароль хранится только в секретах Vercel и локальной закрытой конфигурации. Аналитические материалы и сервер защиты находятся вне Git в `analysis/retention-site/`.

## Работа

Приложение работает с настроенными PostgreSQL и моделью; исходные CSV не нужны для запуска, сборки или выполнения восьми скиллов. Настройки перечислены в `agent-app/.env.example`. Миграции находятся в `db/migrations/`, генераторы синтетических данных — в `scripts/db-generate*`.

Для локальной аналитики: `python3 -m http.server 8766 --bind 127.0.0.1 --directory analysis/retention-site`. Защищённая публикация выполняется из локального пакета `.local/analytics-protected-deploy/`, связанного с проектом аналитики в Vercel. Пакет использует подтверждённую учётную запись владельца; обезличенный автор публичного Git не подходит для проверки участников Vercel. В новом клоне её нет: для воспроизведения отчёта нужны файлы из приватного архива. Не добавлять их в Git.

Скрипты повторного исследования исходных CSV и импорта исходных правил требуют приватных входных файлов. Они не входят в путь запуска приложения; не заменять отсутствующие источники вымышленными данными.

История распространяемой ветки начинается с очищенного снимка. Предыдущая история остаётся только в приватном архиве. Для публикации используется новый репозиторий `arka-agent`; прежний остаётся приватным, поскольку GitHub продолжает отдавать его старые коммиты по SHA.
