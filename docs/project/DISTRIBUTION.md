# Состав распространяемого проекта

В Git остаются приложение, интерфейс, событийная схема БД, миграции, генераторы синтетических животных, восемь скиллов агента и документация разработки.

Исходные CSV и текст задания удалены. Полная версия сохранена отдельно в приватном архиве. Аналитический код, результаты, цитаты и готовый сайт находятся локально в `analysis/`, но вся папка исключена из Git. Производные выгрузки исходных правил в `rules/` тоже не публикуются. Локальные базы, секреты и настройки Vercel не изменены.

Опубликованная аналитика остаётся без изменений по решению владельца: её содержимое и файлы доступны без пароля. Исключение из Git не закрывает доступ через сайт.

## Работа

Приложение работает с настроенными PostgreSQL и моделью; исходные CSV не нужны для запуска, сборки или выполнения восьми скиллов. Настройки перечислены в `agent-app/.env.example`. Миграции находятся в `db/migrations/`, генераторы синтетических данных — в `scripts/db-generate*`.

Для локальной аналитики: `python3 -m http.server 8766 --bind 127.0.0.1 --directory analysis/retention-site`. Развёртывание аналитики выполняется из этой же локальной папки. В новом клоне её нет: для воспроизведения отчёта нужны файлы из приватного архива. Не добавлять их в Git.

Скрипты повторного исследования исходных CSV и импорта исходных правил требуют приватных входных файлов. Они не входят в путь запуска приложения; не заменять отсутствующие источники вымышленными данными.

История распространяемой ветки начинается с очищенного снимка. Предыдущая история остаётся только в приватном архиве. Репозиторий не переводится в публичный режим этой операцией.
