## Результат

`agent-app/` — полноценное Next.js-приложение на основе официального Vercel AI Chatbot. Локально работают чаты, история, URL сессии, управление чатами, документы и фотографии, приватное хранение файлов, поиск по документам, а также интерактивная таблица животных из базы фермы.

Интеграция базы, tools, состояния таблицы и синхронизации описана в [AGENT-DATA-UI.md](AGENT-DATA-UI.md). Целевые требования к фильтрам, сортировке, группировке и автопагинации зафиксированы в [TABLE-VIEW-REQUIREMENTS.md](TABLE-VIEW-REQUIREMENTS.md); панель реализована, но полная визуальная приёмка не завершена.

## Интерфейс

- Слева: новый чат и список чатов с переименованием и удалением отдельного чата; массовое удаление и отдельная ссылка-логотип отсутствуют.
- Вверху чата: только редактируемое название; бренд, приватность и управление доступом временно скрыты.
- Справа: постоянная область просмотра; таблица позволяет менять колонки, дерево фильтров И / ИЛИ / НЕ, сортировку и группировку, а также открывать карточку животного. Выбранная ферма ограничивается сервером независимо от пользовательских фильтров; отдельного расширенного режима нет.
- Внешний вид и состояния компонентов используют цвета, системный шрифтовой стек и радиусы из `prototype/shared/tokens.css`; компоненты без hover, pressed, focus и применимых active/open/disabled состояний не принимаются.
- DOCX и XLSX сохраняются и индексируются; для них пока показывается карточка файла и скачивание.
- Файлы доступны только владельцу сессии через авторизованный API route.
- Поддерживаемый размер одного файла — до 20 МБ.

## Данные продукта

| Хранилище | Что хранит |
|---|---|
| PostgreSQL `arkasha_chat` локально; production — Neon Free | Пользователи, чаты, сообщения, представления таблиц, документы-артефакты, метаданные файлов и извлечённый текст |
| PostgreSQL `arka_test` | Фермы, животные, события и пересчитываемая проекция для чтения |
| Vercel Blob private store | Исходные файлы и фотографии |
| Браузер | Ввод, локальное состояние панели, раскрытие групп по viewId и последний маршрут ассистента |

Исходная база фермы `arka_test` подключена отдельным серверным соединением `FARM_DATABASE_URL`; факты фермы не копируются в продуктовую базу. Доступ ограничивается `farm_access` и RLS, запросы агента проходят только через типизированные tools.

## База знаний

При загрузке извлекается текст из TXT, Markdown, CSV, JSON, PDF, DOCX и XLSX. Перед запросом выбираются до трёх документов, совпадающих с терминами запроса; их содержимое добавляется в закрытый серверный контекст. Изображения и вложения передаются модели через приватный серверный маршрут.

## Модель

Локально агент работает через официальный `codex app-server` и использует текущую подписку ChatGPT. Вход выполняется один раз командой `codex login`; Codex хранит сессию в `~/.codex`, поэтому перезапуск Next.js и компьютера не требует нового входа. Статус проверяется командой `codex login status`.

```dotenv
AI_RUNTIME=codex-app-server
CODEX_CLI_PATH=/opt/homebrew/bin/codex
CODEX_MODEL=gpt-5.6-sol
```

История сообщений хранится в продуктовой Postgres. На каждый запрос приложение запускает изолированный turn Codex, передаёт ему историю текущего чата, видимое состояние таблицы и типизированные tools базы фермы. Файл авторизации не копируется в проект и не попадает в Git.

Для развёрнутого Vercel-стенда используется OpenAI-compatible провайдер или Vercel AI Gateway: подписка ChatGPT не даёт API-доступа, а облачный runtime не имеет доступа к локальному `~/.codex`.

| Переменная | Значение |
|---|---|
| `AI_PROVIDER_BASE_URL` | Base URL API провайдера |
| `AI_PROVIDER_API_KEY` | Секретный ключ |
| `AI_MODEL_ID` | Точный model ID |
| `AI_MODEL_VISION` | `false`, только если модель не принимает изображения |

Без этих переменных и без `AI_RUNTIME=codex-app-server` используется резервный Vercel AI Gateway; его вызовы требуют активированного биллинга. Секреты не попадают в Git или клиентский код.

## Окружение

Обязательные переменные: `AUTH_SECRET`, `POSTGRES_URL`, `BLOB_READ_WRITE_TOKEN`. `AUTH_SECRET` и private Blob уже созданы в Vercel. Создание production Neon ожидает принятия условий Marketplace владельцем команды.
